How it works

Four steps, every one logged and hashed.

The 2×2 factorial

Two suspect steps. Fix each alone, then both.

The planner names two suspect steps. Code applies only those edits and runs four versions on three seeds. If fixing both removes more than the two fixes separately, the flaws interact. All of these cases are synthetic: we built them.
