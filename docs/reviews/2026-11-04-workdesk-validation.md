# Research Workdesk rebuild — 4 November 2026

Current local implementation, not a new scientific cohort or public release. The owner explicitly requested an agent discussion room, full implementation and desktop/mobile browser checks. That later request superseded the earlier no-walkthrough restriction. No live model calls, new credit spending, commit, push, deployment, video publication or submission were performed for this rebuild.

## Implemented product boundary

- Landing: Hero, Method and Scope & Evidence; continuous full-page canvas animation behind the hero, pause/reduced-motion/hidden-tab behavior, Workdesk primary action.
- `/workdesk`: persistent question-first investigations; exact-byte CSV/Python/UTF-8 note materials; local or acknowledged optional Meta guidance; author-reviewed briefs/plans; dispatch into the existing engine; actual progress, finalized results/objections and verified exports.
- `/evidence`: read-only From claim to evidence with original labelled manufacturing recordings and Return to the evidence. Saved own-data audits hide the unrelated manufacturing context. No fullscreen requirement or fresh-run control.
- `/architecture`: animated inspectable stages explaining actual Spark/Wonder/guard/execution/evidence responsibilities. Animation is explanatory, never a live agent trace.
- Self-hosted Space Mono/Inter, shared centered wordmark/header, compact footer, consistent navigation and mobile task views.

Supported scope remains binary numeric tabular evaluation, a generated CSV baseline, or acknowledged trusted compatible Python. No general paper/notebook reproduction, literature search, arbitrary research professor, outside-user evidence or validated local-model quality is claimed. Guidance four attempts/$0.25 per investigation and audits four/$1 per job are reserved admission envelopes, not global account billing limits.
