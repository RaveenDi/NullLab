# Prospective evaluation protocol

Status: prepared after development demonstrations; no claim this protocol predates them. The SECOM variants and earlier cases are development/demo evidence and must not be counted as unseen tests. No independent prospective test has yet been run under this protocol.

Freeze the exact current engine, contract, provider settings and prompt payloads before selecting/adapting new case families. A reviewer who did not tune the instrument should prepare at least three clean and three flawed cases from distinct nonpolitical/nonmedical domains, plus unsupported and ambiguous inputs. Keep ground truth outside planner/critic contexts. An AI-prepared set remains internal AI evaluation; it does not establish external-user adoption or independent human adjudication.

Compare rules, one model with matched context/allowed answers and no execution, the same planner plus execution, and planner plus independent critic plus execution. Use the same model ID, intended-use information, admissible operations and predeclared budget envelope. Record actual cost/latency differences rather than silently equalizing successful calls after failures. No searches for known corrections during blinded assessment.

Outcomes per case: supported intake, original reproduction, expressible control, valid control, executed result, legitimate conclusion, false accusation, abstention and harness failure. Report denominators by case family, not repeated seeds as independent projects. A model no-flaw proposal is not a measured clean result. Preserve the initial pre-execution effect estimate and compare it with the executed effect only when the numerical estimand matches.

Retain all scheduled cases and failed attempts. Any prompt, guard, DSL or template changed after inspecting the cases turns those cases into development evidence. Do not then relabel a later rerun held out. Critic disagreement is a recorded outcome; consensus does not substitute for ground truth. Do not claim superiority unless differences are supported by this matched prospective evaluation.
