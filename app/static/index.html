        02 / THE METHOD
        An argument you can test.
        Reasoning proposes the control.
        The experiment supplies the numbers.
        ↳
        FIRST, THE ORIGINAL
        Establish the baseline.
        Identify the claim, inputs and evaluation contract. Reproduce the starting score before attributing a difference.
        ⌘
        THEN, THE ASSUMPTION
        Make a specific challenge.
        Rules or Meta reasoning propose a constrained intervention. A methodology critic can dispute whether that test is legitimate.
        ⌁
        FINALLY, THE EVIDENCE
        Measure. Explain. Export.
        Inspect the tested change, effects and uncertainty. Preserve the input identity and a record another person can inspect.
        
  
        03 / KNOW WHAT THE EVIDENCE SAYS
        A precise conclusion
        is a useful conclusion.
        NullLab audits supported Python evaluation pipelines. An unsupported input, an untested model judgment and an experiment with no detected effect are different outcomes.
        The manufacturing benchmark uses real public records with explicitly constructed evaluation variants. It demonstrates the instrument; it is not an allegation about a published study or evidence of deployment impact.
