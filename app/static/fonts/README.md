# Bundled typography

Space Mono is used for headings, the wordmark and monospaced technical labels. Inter is used for body text, navigation, form controls and buttons. The CSS declares system fallbacks for unsupported glyphs and uses `font-display: swap`.

The four WOFF2 Latin subset files are unmodified responses from the official Google Fonts CSS distribution. They are served locally; runtime pages do not request fonts from a third party. `SOURCES.json` records source URLs, exact SHA-256 hashes, weights, styles and the retrieval timestamp.

Space Mono regular (400), bold (700) and italic (400) are included. The Inter normal variable face supports weights 100–900. Font bytes total 99,800; complete SIL Open Font License notices are retained in `SpaceMono-OFL.txt` and `Inter-OFL.txt`. These font files retain their own license rather than the repository's MIT code license.

Official source directories: [Space Mono](https://github.com/google/fonts/tree/main/ofl/spacemono), [Inter](https://github.com/google/fonts/tree/main/ofl/inter).
